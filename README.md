### Mealzo | Food Recipe Website

# Mealzo is a responsive food recipe website built using React.js library.
Users can search for recipes, add their own recipes, bookmark favorites and delete their own recipes.
It fetches live data from an external REST API and provides a seamless recipe management experience.

### 🛠️ Tech Stack
- ⚛️ React.js  
- 🗂️ Redux  
- 🌐 REST API  
- 📜 JavaScript (ES6+)  
- 🎨 CSS3 (Flexbox, Media Queries)  
- 🏗️ HTML5  

### Features
# 🚀 Implemented Redux for efficient state management and to handle global application data seamlessly.
# 🔍 Search recipes in realtime using input search functionality powered by debouncing to reduce server load.
# ➕ Add a new recipe using a custom form that contains title, image url, recipe url, servings, publisher, cooking time , servings and ingredients.
# 🔖 Provided a bookmark toggling feature to save your favourites recipes.
# 🗑️ Users can delete only the recipes they’ve created, with a sleek side prompt confirming the action.
# 📱 The website is built with a fully responsive design ensuring a seamless and consistent user experience across all screens and devices using Css flexbox, media queries and responsive sizes.
# 🔒 Implements a frontend-based login validation system to restrict unauthorized access to protected routes.

## The website is accessible at: https://mealzo.netlify.app/
